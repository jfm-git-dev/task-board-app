# Kanban Task Board
**A High-Performance Productivity & Workflow Interface**

A fully-featured Kanban-style task management application designed for speed, clarity, and real-time collaboration. Built with **React**, **TypeScript**, and **Supabase**, this platform mirrors the user experience of industry-leading tools like Linear and Asana.

## ✨ Key Functionality
- **Real-Time Synchronization:** Seamless data persistence using Supabase (PostgreSQL).
- **Interactive Drag-and-Drop:** Fluid task movement across status columns using the native HTML5 API.
- **Anonymous Authentication:** Instant guest session creation allowing immediate user onboarding.
- **Relational Data Management:** Integrated "Team Roster" and "Task Assignment" systems.
- **Activity Ledger:** Comprehensive history tracking for every task creation and status change.

## 🛠️ Advanced Organization Tools
- **Multi-Criteria Filtering:** Instantly filter tasks by Title, Description, Priority, Assignee, or Custom Labels.
- **Urgency Indicators:** Visual badges and "Overdue" status alerts based on integrated due-date logic.
- **Custom Label System:** Dynamic tag creation for granular task categorization.
- **Task Detail View:** Deep-dive modal for viewing task descriptions and historical activity logs.

---

## 💻 Tech Stack
- **Frontend:** React 18, Vite, TypeScript, Tailwind CSS
- **Backend:** Supabase (Database, Auth, API)
- **Database Architecture:** PostgreSQL with Foreign Key relations and Row Level Security (RLS)
